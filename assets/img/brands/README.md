# Platform logos

Brand marks for the music pages' follow buttons, from
[Simple Icons](https://simpleicons.org) v16.35.0 (CC0 1.0). Each file is
filled with the platform's brand colour; `infinity_music_platform_mark()`
inlines them so a button can recolour the mark with CSS.

The logos remain trademarks of SoundCloud, Spotify and Google (YouTube),
used here only to link to the E.T.'s profiles on those platforms.
